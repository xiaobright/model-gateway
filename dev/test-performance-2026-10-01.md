# 测试选择与耗时优化（2026-10-01）

完整 Python 验证从 **151.84 秒降到 104.94 秒**，约减少 31%；用例从 286 项变为 278 项。
主要收益来自准备和收尾优化，未删掉真实连接测试，也未修改正式网关代码、超时或重试参数。

改动前的未提交功能已保存为本地检查点 `dd0b4a4`。本文记录本次验证，不是以后每次运行的性能保证。
当前命令和测试选择规则见[维护说明](maintenance.md#测试怎么跑)及[项目约定](../AGENTS.md)。

## 实测

同一工作区、Windows 原生运行，使用已有 `.venv`，每个状态各做一次完整基线。

| 范围 | 改动前 | 改动后 |
| --- | ---: | ---: |
| Python 完整执行 | 286 passed，151.84s | 278 passed，104.94s |
| 非网络组 | 271 项，累计 94.61s | 263 项，累计 55.43s |
| 本机网络组 | 15 项，累计 56.33s | 15 项，累计 48.51s |
| Node 行为测试 | 21 passed，0.31s | 20 passed，0.30s |

两组的累计耗时来自对应全量运行中每例 setup/call/teardown 的汇总，不是分别重新运行的墙钟时间；
总和不包含收集及 pytest 的少量额外开销。单次测量受系统负载和缓存影响。

| 代表性用例 | 改动前主体耗时 | 改动后主体耗时 |
| --- | ---: | ---: |
| `test_token_ratio_is_learned_from_the_log` | 7.269s | 0.119s |
| `test_direct_really_turns_the_system_proxy_off` | 2.413s | 0.002s |
| `test_client_leaving_after_completion_event_is_not_flagged` | 6.944s | 1.801s |

采集专项仍有 32 项，本次累计约 4.06 秒；其中写盘及转发挂接仍运行真实采集器。
通用网关 fixture 关闭采集器，避免每个无关用例重复启动和等待后台写盘线程。

## 改动与保留的行为

- pytest 默认只选非网络组，`--network` 选本机网络组，`--full` 才包含全部组；终端显示范围。
  原 `-m network` 命令仍兼容，文件和 `-k` / `-m` 继续缩小范围。严格检查未知 marker，避免网络测试被误拼成普通测试。
- 删除被错误格式测试覆盖的单独 404 用例；将 Host/Origin 的 3 个单独用例并入已有管理接口用例，原断言保留。
- 画布 14 项整理为 10 项：合并坐标/视图存取、非法请求和坏数据库内容；边界组合直接测试解析，
  接口测试中的坏坐标改用真实存在的模型，仍验证响应、落库、剪枝及不影响路由。
- 完成事件跨块测试改用真正的 `AsyncByteStream`。原 ASGITransport 会拼接响应，无法验证网关看到分块时的行为。
  保留完成状态和输入用量断言，并检查输出用量。
- 删除只用正则匹配 CSS 写法的前端用例；实际候选换行算法与异步会话测试保留。
- 统计样本仍为 250 条，改为分批单事务写入；不再为准备数据做 250 次独立提交和关闭连接。
- 参数测试不构造无关 TLS transport；客户端缓存测试使用 MockTransport，保留缓存失效逻辑。
  系统 SSLContext 构造、自签证书、真实代理转发与远程模型列表的网络测试保留。
- 进程内模拟流省去用于观察真实网络过程的延时；网络组时序不变。
  挂起的模拟上游在用例断言后用事件释放，检查线程确实退出，不再把 20 秒 sleep 留给 5 秒 join 超时。
- 新增简短项目指引，明确按改动选检查、何时扩大范围、何时停止，不再把“一批代码改完”作为全量触发条件。

## 验证边界

- 针对性检查：16 passed / 3.71s；真实断流收尾：3 passed / 8.30s。
- 完整验收：`uv run .venv\Scripts\python.exe -m pytest --full -q -p no:cacheprovider --durations=15`，278 项通过。
  记录了每例耗时，并核对验收开始后 Python 应用和测试源文件哈希未改变。
- 只收集核对默认、网络、全量及旧标记命令：263 + 15 = 278，交集为空，并集完整。
  冲突的 `--full --network` 返回使用错误；默认显式选中一个网络用例会被排除并返回无测试执行，不能误报通过。
- 故障注入仅作用于独立测试进程：去掉坐标范围限制后，纯解析和接口用例均断言失败；
  清除跨块缓存后，完成事件用例断言失败。证明改写后的用例能发现这些故障，应用源码未被注入修改。
- Node 20 项通过；Python 测试语法、改动的 Node 文件语法、文档 UTF-8/LF 与本地链接、`git diff --check` 通过。
- Python 仍有一个既有 Starlette/TestClient 弃用警告，本次没有为此升级依赖。
- 未进行真实供应商请求或新的浏览器布局验收；正式网关与正式数据未用于测试。

非网络组整体仍需几十秒；日常应运行与修改相关的文件或用例。更大规模并行化和数据库设施重构不在本次实现范围。
