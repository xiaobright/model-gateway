# NEXUS 控制台样稿（Nexus Console）

本目录保存 2026-10-20 做的一版控制台改版样稿。正式入口仍然是 `/`，运行时不加载这里的文件。

## 访问方式

通过网关静态服务访问：

<http://127.0.0.1:8317/static/experiments/nexus-console/index.html>

不要直接双击 `index.html`。页面用相对路径请求 `/admin/api`，`file://` 下拿不到数据，只会看到空态和报错提示。

## 设计重点

1. **深空玻璃视觉**
   - 近黑底、极光色团、细噪点与跟随鼠标的粒子连线；卡片使用渐变描边与局部高光。
   - 深色为默认形态，浅色是完整的一套主题，可随时切换并记住选择。

2. **路由星系**
   - 下游模型在内圈、上游站点在外圈，连线按接口着色；保存的首选上有流动光点。
   - 悬停聚焦一个模型：其余节点压暗、相关站点高亮、连线变成流动虚线。
   - 点击模型展开候选链与「查看详情 / 启用首选 / 看实时」；点击上游站点跳到「上游」并高亮那张卡片。
   - 节点位置做过碰撞消解，名字长的模型不会互相压住；窄屏改成横向滑动，标签保持可读。

3. **总览**
   - 请求、输入、输出、缓存命中、P95 五张指标卡，带迷你趋势与前后半窗对比。
   - 流量地形图支持 1 小时 / 24 小时 / 7 天，悬浮十字线读数、失败量叠加、空窗口提示。
   - 实时脉动卡、上游健康环、模型热度条，全部使用当前时间窗的真实聚合。

4. **六个视图**
   - 总览、模型、上游、实时、记录、设置；模型详情抽屉支持设首选、前移后移、移除、重命名、整条链交接、删除。
   - 上游支持站点/分组启停、三出口探测、复制地址；实时支持中断；记录支持筛选与单次详情；设置里能改接口开关、自动换站、发呆超时。

5. **命令面板与响应式**
   - `Ctrl K` 搜索视图、模型、站点和常用动作；深色/浅色、桌面/平板/手机三档布局。
   - 轮询刷新不会重播入场动画；系统开启「减少动态效果」时全部收敛。

## 与其它样稿的区别

`console-redesign` 和 `home-styles` 里的是纯前端模拟数据，怎么点都只影响当前页面。这一版**直接连正在运行的网关**：

- 读：概览、模型链、上游、实时请求、转发记录、接口开关、降级设置、发呆超时、接入地址。
- 写：设首选、调候选顺序、移除候选、重命名、整条链交接、启停站点/分组/接口、探测出口、改超时、关闭网关。

所以它不是安全沙盒：删除、停用、关闭这类按钮会真的落到 `data/gateway.db` 或当前进程上。只是看界面时不要顺手点危险操作。

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面骨架与六个视图容器 |
| `styles.css` | 全部样式、主题变量与响应式规则 |
| `js/core.js` | API 封装、格式化、轻提示、确认框、背景粒子场 |
| `js/chart.js` | 流量面积图与悬浮读数 |
| `js/galaxy.js` | 星系布局、碰撞消解与交互 |
| `js/app.js` | 状态、渲染、轮询与操作闭环 |

纯原生 ES 模块，没有外部依赖和构建步骤。

- 无头 Chrome 在 1600 / 1024 / 420 三档走过：六个视图、命令面板、抽屉、搜索筛选、图表悬浮、星系选中与上游跳转、主题切换，控制台无报错。
- 归档只移动了目录；迁移后用新地址复跑一次，10 条模型链与 12 个站正常加载。

## 重新启用

想把 NEXUS 作为正式入口，需要把目录移回 `web/nexus/`，在 `gateway/app.py` 加一条 `/nexus` 路由（或改 `/` 返回的文件），然后重启一次网关。本轮没有改后端。
