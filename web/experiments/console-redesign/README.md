# 控制台重构原型样稿（Console Redesign Prototype）

本目录包含针对 Model Gateway 控制台的前端改版可交互样稿。

## 访问方式

- **本地直开**：在浏览器中直接双击打开 `console-demo.html`。
- **网关运行时**：通过网关静态服务访问：
  <http://127.0.0.1:8317/static/experiments/console-redesign/console-demo.html>

## 设计重点与实验特性

1. **石墨工作台视觉质感（Graphite / Solid Panel）**
   - 移除原版透明毛玻璃与重度背景模糊，采用不透明实体面板（提供深色深灰石墨色与浅色双主题切换，持久化至 `localStorage`）。
   - 1px 精细边框与高对比度文字排版，模型名称统一使用等宽字体（`Cascadia Mono` / `JetBrains Mono` / `Consolas`）。
   - 协议固定配色：Responses（蓝）、Chat（青）、Messages（橙）；状态语义固定：绿（正常）、黄（冷却/降级/无内容）、红（异常）、灰（停用/备用）。

2. **模型路由：横向候选卡片链（取代原版复杂气泡网络）**
   - 核心工作台采用左侧模型快速检索列表（带 30 分钟迷你流量火花图）+ 右侧横向流水线卡片。
   - 卡片直观标示「当前起点」与「首选」，支持卡片拖拽排序与 `◂` `▸` 微调、一键设为首选。
   - 支持跨模型整条链交接（带成环检测和断链告警卡片）。

3. **流量关系图（Flow View）**
   - 自动三列分层排布：`客户端 → 下游模型 → 上游分组`。
   - 连线粗细由流量加权，虚线标示冷却中与交接，不需用户手动保存或拖拽坐标。

4. **实时请求瀑布时间轴（Live Waterfall）**
   - 类似浏览器 DevTools Network 时间轴：`等响应头 → 首字 (TTFT) → 流式输出 (TPS) → 无内容监控 / 超时`。
   - 发生故障自动换站时，单行内连续分段展示（如 `站点B 429 › 站点A 流式中`）。
   - 独立分组熔断与冷却倒计时面板。

5. **统一排查抽屉与全局功能**
   - 实时流与历史记录点击统一唤起侧边抽屉，提供完整的单次请求阶段耗时、多次尝试经过、Token 估算，以及一键「复制排查信息」。
   - `Ctrl+K` 全局命令面板（Command Palette），快速搜索模型、切换视图、修改换站开关。
   - 底部常驻状态栏：活跃请求计数、协议状态、换站开关、网关接入地址一键复制。

## 数据与独立性

- 样稿内所有数据（模型、候选、站点、健康度、实时请求流水）均为**前端内置模拟数据**。
- 不请求后端 Admin API，不调用真实模型与上游，不改动 `data/gateway.db`，可安全在任意环境测试操作体验。
