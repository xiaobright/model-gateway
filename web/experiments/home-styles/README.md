# 首页风格备用样稿

本目录集中保存未启用的首页实验，供以后比较、替换或融合。正式首页继续使用现有版本，运行时不加载这些样稿。

- [四种风格对比](home-style-gallery.html)：网关运行时打开 <http://127.0.0.1:8317/static/experiments/home-styles/home-style-gallery.html>。顶部可切换单版或并排比较，也可在浏览器内收藏喜欢的风格。
- [液态玻璃实验](liquid-glass-lab.html)：网关运行时打开 <http://127.0.0.1:8317/static/experiments/home-styles/liquid-glass-lab.html>。保留 CSS、均衡、极致三档和测量面板。
- [液态玻璃性能记录](liquid-glass-benchmark.md)及[原始测量数据](liquid-glass-benchmark.json)：保留实验当时的对照结果与适用边界。

两个 HTML 都可直接打开；建议通过上面的网关地址访问，以便从样稿返回正式首页。迁移前位于 `/static/` 根目录的旧样稿链接已由上述入口替代。

| 方案 | 视觉方向 | 适合借鉴的部分 |
| --- | --- | --- |
| 云雾玻璃 | 蓝紫环境色、浓度更高的正文面板、局部磨砂 | 延续现版材质，同时改善文字与背景的分离 |
| 石墨工作台 | 不透明深色、紧凑行距、细边框 | 信息密度、等宽模型名、清晰的状态层级 |
| 暖纸工作室 | 暖灰纸色、鼠尾草绿、横向导航、衬线标题 | 柔和底色与配色，适合不喜欢冷白的人 |
| 雾蓝陶瓷 | 实体浅色面板、轻微凸起按钮、窄侧栏 | 控件的触感与正文的稳定底色 |

建议优先比较“云雾玻璃的导航与环境色 + 雾蓝陶瓷的正文和控件”。如果模型较多，可以再借鉴石墨版的行距和信息密度，无需把整页改成深色。

## 与正式页面的关系

- 正式入口仍是 `/#routes`，本次没有修改正式首页。
- 较透明的液态玻璃实验及相关性能记录与四种风格样稿一同保存在本目录。
- 新样稿使用相同的演示模型，支持筛选、选择、首选切换和临时新增。所有操作只影响当前页面；收藏仅保存于本浏览器的 `mg-style-favorites`。
- 样稿不读取网关配置、不请求管理 API、不调用供应商。未实现的正式功能入口会提示返回现用主页。

## 开销与验证

使用原生 HTML/CSS/JS，无外部素材、依赖、WebGL 或持续动画循环。云雾版只有侧栏和详情使用局部背景模糊；其他三版没有背景模糊。悬停、按压、切换与弹窗使用有限时长的过渡，并尊重减少动态效果偏好。

并排比较时额外加载四个独立样稿 iframe，因此它的资源占用不代表未来单版首页。此前液态玻璃实验的跑分不能套用于本页；本轮未测量 GPU 开销。

创建样稿时已验证：内联脚本语法、重复 HTML ID、桌面四版实显、390px 窄屏与并排布局，以及筛选、模型选择、首选同步、转发跳转、临时新增等演示交互。归档迁移只调整文件位置和入口链接，未重新进行性能测量。

浏览器控制台另有内置浏览器注入脚本的 MutationObserver.observe 错误：堆栈指向无 URL 的 Node 包装脚本，而本页只有 ResizeObserver；并排缩略图和交互仍正常。此问题未修改浏览器端实现。
